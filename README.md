# 내 포트폴리오

HTML/CSS/JS로 만든 간단한 포트폴리오 사이트입니다. 빌드 도구 없이 바로 동작합니다.

## 📁 파일 구조

| 파일 | 설명 |
|------|------|
| `data.js` | ✏️ **내용 수정은 여기서!** 이름, 소개, 기술, 프로젝트, 경력, 연락처 |
| `index.html` | 페이지 뼈대 |
| `style.css` | 디자인 (색상은 맨 위 `:root`의 `--accent` 등을 바꾸면 됨) |
| `script.js` | `data.js` 내용을 화면에 그려주는 코드 |
| `assets/` | 프로필 사진, 프로젝트 이미지 넣는 폴더 |

## ✏️ 수정 방법

1. `data.js`를 열어 이름·소개·프로젝트 등을 내 정보로 바꿉니다.
2. 사진은 `assets/` 폴더에 넣고 `photo: "assets/profile.jpg"`처럼 경로를 적습니다.
3. 프로젝트를 추가하려면 `projects` 배열에 `{ ... }` 블록을 하나 복사해서 붙여넣으면 됩니다.

## 👀 내 컴퓨터에서 보기

`index.html`을 브라우저로 더블클릭해서 열면 됩니다.

## 🌐 GitHub Pages로 배포하기

1. 저장소 **Settings → Pages** 이동
2. **Source**: `Deploy from a branch` 선택
3. 브랜치(`main` 등)와 `/ (root)` 폴더 선택 후 **Save**
4. 1~2분 뒤 표시되는 주소로 접속하면 포트폴리오가 보입니다.
